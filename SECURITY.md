# Security Policy

## Reporting a Vulnerability

If you discover a security issue in this project, please report it by opening an issue and clearly marking it as a security or vulnerability report.

Include the following information:
- A clear description of the issue
- Steps to reproduce it
- The expected and actual behavior
- Any relevant environment details

## Supported Versions

This repository is intended for local development and demo use. There is no formal support policy for released versions.

## Responsible Disclosure

Please do not publicly disclose vulnerabilities until they have been addressed.

## Security Contact

If no direct security contact is available, use the repository issue tracker and tag the report as a security issue.
