# Contributing to VELOX

Thank you for your interest in contributing to VELOX. The project is built with Vite, React, and TypeScript, and contributions are welcome from collaborators who want to improve the trainer experience.

## How to contribute

1. Open an issue first if you want to propose a new feature or report a bug.
2. If you are ready to contribute code, fork the repository and create a branch from `main`.
3. Keep changes small and focused.
4. Add tests for new functionality or bug fixes when appropriate.
5. Follow the existing TypeScript, React, and project style conventions.

## Development workflow

- Run `npm install` to install dependencies.
- Use `npm run dev` to start the local development environment.
- Run `npm run type-check` before submitting a pull request.
- Run `npm run lint` to catch formatting and lint issues.
- Add or update tests with `npm test`.

## Pull request checklist

- [ ] The code builds successfully
- [ ] Type checking passes (`npm run type-check`)
- [ ] Linting passes (`npm run lint`)
- [ ] Tests pass (`npm test`)
- [ ] The PR description explains the problem, the solution, and any relevant context
- [ ] New behavior is covered by tests or manual validation steps

## Copilot and automation

If you use Copilot or other AI-assisted tools, please review generated code carefully before submitting. Make sure it follows project conventions and does not introduce regressions.
